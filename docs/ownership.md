# What you must own

Fallout: Crossroads never ships Bethesda game files.

| Required | Build |
|---|---|
| Fallout 3 (PC) | **1.7.0.3-class** (GOG 1.7.0.3 or Steam downgraded) |
| Fallout: New Vegas (PC) | Steam **1.4.0.525** |

You configure install folders in the launcher. Paths stay under
`%AppData%\FalloutCrossroads\`. Runtime may junction/hardlink **your** Fallout 3
BSAs into the New Vegas `Data\` folder as `CR_FO3_*` so meshes resolve — those
files remain yours; they are not copied into git or redistributed.
